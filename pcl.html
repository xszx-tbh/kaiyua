PCL2 下载功能修复工具

根目录未放置 pcl.zip 时，请使用 GitHub 方式获取 2.14.0.0

法一：下载旧版本 PCL2，恢复下载功能

2026 年 10 月 20 日，PCL2 更新到 2.99.0.0， 移除了 MC 下载与整合包安装功能[reference:0]。 最后一个功能完好的正式版是 2.14.0.0。 把旧版 exe 覆盖回去，并在启动后关闭自动更新，即可恢复下载。

获取旧版 PCL2

方式 A（推荐）：直接使用本页面根目录的 pcl.zip

  1. 点击上方 下载根目录 pcl.zip。
  2. 解压 pcl.zip，里面应该是旧版 PCL2 的文件（通常包含 Plain Craft Launcher 2.exe）。
  3. 跳过下面的 GitHub 步骤，直接看“替换与关闭更新”。

如果点击后提示文件不存在，说明根目录没有放 pcl.zip， 请使用方式 B，或自行把旧版 PCL2 的压缩包放到与这个 HTML 相同的目录下并命名为 pcl.zip。

方式 B：从 GitHub Releases 获取 2.14.0.0

  1. 打开 https://github.com/Meloong-Git/PCL/releases/tag/2.14.0.0[reference:1]。
  2. 在页面底部的 Assets 区域，点击 Source code (zip) 下载源码压缩包[reference:2]。
  3. 解压后，找到里面的 最新正式版.zip，再次解压，得到 PCL2 的可执行文件[reference:3]。

替换与关闭更新（关键步骤）

  1. 1 先断网（关闭 Wi-Fi / 拔掉网线）[reference:4]。
  2. 2 用旧版 PCL2 的 Plain Craft Launcher 2.exe 覆盖掉你原来被更新后的启动器文件[reference:5]。
  3. 3 在断网状态下打开 PCL2，进入 设置 → 启动器 → 启动器更新，选择 关闭更新提示， 弹窗点“我知道我在做什么”[reference:6]。
  4. 4 如果你担心“只关提示”拦不住强制更新，可以额外在 PCL 目录的 Setup.ini 中加入或修改：
    SystemSystemUpdate=3
    保存后再联网[reference:7]。
  5. 5 联网，此时下载功能应该已经恢复。

风险提示：不要从任何第三方“修复版”“绿色版”网站下载 PCL， 已经有报告称第三方文件携带病毒[reference:8]。只从 GitHub 官方仓库或你自己确认可信的来源获取旧版。

法二：JSON 补全法

如果暂时不想换回旧版 PCL2，可以用这个页面下载目标版本的 版本 JSON，打包成 <版本号>/<版本号>.json 的 ZIP。 解压到 .minecraft/versions/ 后，PCL2 会把该文件夹识别为一个“不完整的版本”， 启动它时会触发补全，从 Mojang 官方源拉取缺失的 Jar 和库文件。

  1. 在下方表格中选择你要玩的版本，点击 下载 ZIP。
  2. 解压得到的 .zip，你会看到类似 1.20.1/1.20.1.json 的结构。
  3. 把整个 1.20.1/ 文件夹放进 PCL2 的 .minecraft/versions/ 目录。
  4. 打开 PCL2，在版本列表里应该能看到这个版本。直接启动它。
  5. PCL2 检测到文件不全，会自动弹出补全提示，确认后开始从官方源下载缺失文件。

也可以点 下载全部为 ZIP，一次把所有正式版的 JSON 打包下载。

点击“获取正式版 JSON”，从 Mojang 官方清单读取所有正式版的版本 JSON。
